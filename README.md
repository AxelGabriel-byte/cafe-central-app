# cafe-central-app
Cafetería Central es una aplicación web que permite a los clientes consultar el menú de productos, visualizar precios, seleccionar alimentos y bebidas, realizar pedidos y consultar el estado de sus pedidos desde un dispositivo móvil o una computadora.
PROPOSITO:
La aplicación busca facilitar la consulta del menú y la realización de pedidos en la cafetería, permitiendo a los clientes conocer los productos disponibles, revisar sus precios y dar seguimiento a sus pedidos de manera rápida y sencilla.

FUNCIONALIDAD PRINCIPAL:
Consultar el menú de alimentos y bebidas.
Visualizar los precios de los productos.
Seleccionar productos y cantidades.
Crear y registrar pedidos.
Calcular el total de la compra.
Consultar el estado del pedido.
Utilizar la aplicación desde dispositivos móviles y computadoras.

TECNOLOGIAS QUE PUEDEN UTILIZARSE:
HTML5: para crear la estructura de las páginas web.
CSS3: para diseñar la apariencia de la aplicación.
JavaScript: para agregar interactividad.
React: para desarrollar interfaces dinámicas.
Node.js: para ejecutar la lógica del servidor.
Express: para gestionar las solicitudes y los pedidos.
MySQL: para almacenar los productos y la información de los pedidos.
Git y GitHub: para controlar las versiones y colaborar en el desarrollo.
